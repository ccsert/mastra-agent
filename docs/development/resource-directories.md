# 能力目录与内容分页

2026-09-09，基线 `f4f6fcf`。本轮解决工作流能力目录静默截断和逐项查询，并让会话、知识库文档按需加载。

## 工作流能力目录

`modules/workflows/catalog.ts` 负责能力描述、固定版本依赖筛选和 AI 编排范围。公开入口仍是 `Workflows.catalog()`，权限、发布与执行由原领域接口负责。

- 原目录只读取最新 100 个工具和 100 个 Agent 发布版本，旧版本会从编排选项中消失；现在返回项目内全部当前可用的能力，保持工具和 Agent 分组、创建时间/ID 倒序。
- 一次项目访问检查、一次工具查询、一次发布版本查询，共 3 次 SQL。数据库只向应用返回公开能力元数据和工具 Schema，不读取凭据密文或整个 Agent 发布快照。
- Agent 能力依据固定发布快照检查模型、工具、知识库、向量/重排模型及 Skill 依赖。MCP 导入契约与服务启用状态、Skill 版本启用状态与 digest 均需匹配；某版本依赖失效只移除该能力，不阻断无关目录。未发布的 Agent 改名不会改变历史版本描述。
- 目录读取不授予执行权限，也不替代发布和 Runtime 执行时的依赖校验。目录返回之后发生的停用仍由执行链处理。

查询次数固定不代表执行时间固定。目录仍完整加载，传输量和内存随资源数量增长；远程搜索、服务端能力选择及容量基线尚未完成。252 条能力的回归是正确性与查询次数检查，不是负载测试。

## AI 编排范围

生成候选支持可选的 `capabilityIds`，最多 200 个工具或 Agent 发布版本 ID。控制台提供能力多选；未选择时使用完整目录。SDK 显式传入 `[]` 时只保留已保存草稿引用的能力。服务端始终自动保留草稿引用的工具与固定 Agent 版本。

不可用或其他项目的 ID 返回 `409 DEPENDENCY_UNAVAILABLE`；筛选后目录的 JSON 字符串长度超过 160,000 时返回 `400 CATALOG_LIMIT`，提示缩小范围，不截断后继续调用模型。这里是字符长度保护，不是模型 token 预算。缩小范围不修改 Agent 授权或已发布流程。

生成任务在锁定草稿并确认修订后读取目录，将最终范围写入该任务快照；模型候选仍须经过原有结构、绑定、能力与修订校验才能接受。具体调用见 [SDK 说明](../../packages/sdk/README.md)。

## 会话与文档分页

`listConversations` 和 `listKnowledgeDocuments` 新增 `limit`（1–100）、`cursor`，响应正文保持数组，`X-Next-Cursor` 提供后续位置。**省略参数现在最多返回 100 条；把旧响应当作完整目录的调用方必须继续跟随游标。** OpenAPI 与 SDK 由原有 Hey API 流程生成。

- 会话游标绑定租户、项目、调用者及入口，文档游标绑定租户、项目和知识库；每页重新鉴权，跨范围游标拒绝。
- 顺序为创建时间/ID 倒序，保留 PostgreSQL 微秒精度。删除游标指向的记录不影响继续读取；新记录通过重新读取第一页发现，不承诺分页期间的数据快照。
- 会话固定 2 次 SQL，文档固定 3 次 SQL，包含访问检查。文档列表查询只取元数据，不读取正文，并排除已删除文档。
- 控制台每页 20 条，显示已加载数量与“加载更多”。翻页失败保留已有页面并支持重试；关闭详情或离开页面取消在途请求。知识库标题使用服务端文档总数，不把已加载条数当作总量。
- 共享查询入口在类型上禁止会话、工作流使用单页加载器，避免后续页面把第一页误作完整目录。知识库文档查询归知识库功能模块维护。

数据库迁移 v7 新增会话、有效文档、MCP 导入契约和发布目录索引，通过既有迁移锁随安装包执行。使用普通事务索引迁移；大规模在线环境仍需单独设计迁移窗口，见 [部署说明](deployment.md)。
