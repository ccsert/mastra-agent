# 控制台路由与页面状态

2026-09-09，基线 `c24b2f8`。原控制台将项目、主页面和详情对象保存在组件状态中；现在由 URL 确定项目、页面及六类资源详情，支持深链接、刷新和浏览器前进后退。

## 地址设计

所有业务页面位于 `/projects/:projectId` 下，统一生成地址并正确编码路径参数。

| 地址后缀 | 页面 |
| --- | --- |
| `/overview` | 项目工作台 |
| `/agents` | Agents |
| `/skills`、`/skills/:resourceId` | Skill 目录、固定版本详情 |
| `/chat`、`/chat/:resourceId` | 会话目录、指定会话 |
| `/knowledge`、`/knowledge/:resourceId` | 知识库目录、指定知识库 |
| `/workflows`、`/workflows/:resourceId` | 工作流目录、流程编辑会话 |
| `/models` | 模型服务 |
| `/tools` | 工具 |
| `/mcp`、`/mcp/:resourceId` | MCP 服务、能力管理 |
| `/runs`、`/runs/:resourceId` | Agent 运行目录、运行详情 |
| `/applications` | 应用接入 |
| `/runtimes` | Runtime 状态 |

`/` 在登录后进入首个可访问项目；没有项目时显示创建入口。项目根地址进入该项目工作台。未知页面或不存在/无权访问的项目显示明确错误，不自动切换到另一个项目，不向不可访问项目加载资源。

菜单是真实链接，保留复制链接、新标签页和浏览器历史语义。切项目进入新项目工作台；页面标题和菜单选中状态来自路由。创建表单、一次性凭据、未保存字段、画布缩放与节点选择等临时状态仍属于界面，不进入 URL。Agent 编辑抽屉与工作流内部运行/发布弹窗尚未提供独立链接，本轮不声称所有弹窗都已经路由化。

## 登录与权限

未登录的深链接进入 `/login?returnTo=...`，登录后回到原地址。认证入口先完成回跳，再挂载项目，避免默认项目跳转覆盖目标。返回地址只允许控制台内部路径；外部 origin、协议相对地址和反斜线等输入不会触发外部跳转。主动退出回到登录页，重新登录建立干净工作空间。

URL 中的项目 ID 只是定位信息。工作空间验证可访问项目目录，详情请求继续由后端鉴权。新增 `getConversation` 复用会话现有的项目、调用者和入口检查；通过生成 SDK 按 ID 读取元数据，使第一页以外的历史会话也能直接打开。OpenAPI/SDK 由 Hey API 自动生成。

## 模块归属与生命周期

- `app/routing/routes.tsx` 声明 React Router 路由树；生产使用 browser router，组件回归使用同一路由树的 memory router。
- `Workspace` 管理项目目录及访问检查；`ProjectConsole` 负责导航框架、项目选择和临时编辑器。`ProjectPage` 将路由参数转换为功能模块的选择意图，通过 `Outlet` 挂载对应页面。没有在原 `page` 状态外增加第二份 URL 镜像。
- 功能模块接收 `selectedId/onSelect`，拥有各自数据读取与错误状态；工作流、会话、Skill 和运行详情按 ID 读取，不依赖已加载的列表页。知识库和 MCP 仍使用现有完整目录，并对错误 ID 明确提示，禁止退回第一项。
- 项目缓存继续由 TanStack Query 管理。URL 改变项目或认证身份时卸载旧项目缓存并取消请求；关闭详情取消正文和事件请求。运行详情的请求与事件分页也迁入功能查询，删除手写请求序号。
- 工作流草稿继续归 FlowGram Form/History。打开流程读取保存的版本，后台目录刷新不会覆盖编辑中的草稿；离开后重新打开会重新读取保存状态。

## 离开保护

`NavigationGuard` 将工作流原有的 busy/dirty 判断接入 React Router `useBlocker`。菜单、返回列表、切项目、程序导航和浏览器 POP 共用一个确认框；取消保持原位置与草稿，确认才执行待定导航。连续导航更新待定目的地而不叠加确认框。提交期间阻止离开；刷新或关闭页面使用 `beforeunload`。退出登录另经同一草稿判断后才调用退出接口。

节点字段修改与未保存草稿不通过浏览器历史保存。取消浏览器请求也不表示撤销已完成的服务器写入。
