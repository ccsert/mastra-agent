# 运行轨迹透明度修复与验收

日期：2026-09-09。本记录接续 [DSH 本地对照](dsh-local-trajectory-2026-09-09.md)，针对平台 5179 的输入缺失、空白、分类及系统上下文问题。

后续更新：[会话多轮轨迹与运行记录合并](conversation-trajectory-2026-09-09.md)。当前界面已改为会话轮次阅读，以下步骤视图描述仅保留为本次修复的历史记录。

## 根因与修复

- 历史运行的 `input_text` 为空，但同一会话内保存了用户消息及运行的输入摘要。读取时仅在已授权会话内按原始文本的 SHA-256 精确恢复；不选取“最新消息”猜测，不修改旧数据或幂等键。无法匹配时保留缺失状态。
- 真实订单样例的四个模型步骤重复使用 `txt-0`，旧投影错误合并为一个模型记录。现在按步骤与文本 ID 分组，保留无正文模型步骤，并用单行空态表达。
- 顶部重复输出包含多个开头换行，原样展示挤占轨迹空间。汇总原文改为折叠入口；轨迹默认紧凑展示，详情渲染 Markdown，原始正文仍可检查。
- 输入、模型、工具分别展示概览轨道和筛选入口；记录明确标出系统、用户、上下文、模型、工具与错误类别。

## 请求与来源

Runtime 在现有 OpenAI-compatible provider 的实际请求边界采集白名单正文，包含模型、消息、工具定义和已支持的调用参数。它反映 Mastra 加入 Workspace/Skill 内容之后的请求；不采集认证请求头、API key 或 URL 凭据。正文中业务内容仍属于敏感运行内容，沿用现有运行的项目、用户与调用入口访问边界。

请求作为 `data-model-request` 事件持久化；transient 标记使它不会混进聊天消息正文。Worker 串行投递并发来源的事件，维护连续序号。

新运行的“初始系统提示词”取首次真实请求中的 system/developer 消息。历史运行回退到不可变发布快照，并明确显示“发布版本快照；此历史运行未记录完整模型请求”。这不代表历史完整请求已被恢复。

Run 契约新增 `agentInstructions`，OpenAPI 和 TypeScript SDK 均由现有 HeyAPI 流程生成。

## 仍然存在的边界

当前概览表示调用顺序，接收跨度来自控制面时间戳，尚非模型原生耗时。Token 用量、首 token 时延、真正时间轴、重试请求与步骤的独立关联、超长轨迹虚拟化仍未实现。本轮请求捕获适用于现有 provider 的 JSON 字符串请求体，未宣称覆盖其他模型协议。
