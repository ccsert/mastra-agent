# 对话连续性、轮次过程与工作区

本轮把对话从单次流式输出推进到可恢复、可追溯的任务界面。延续 DSH 的过程与结果分层；消息、流恢复、分组与单个工具展示继续使用 assistant-ui 原生能力。

## 已实现

- 草稿和选定 Skill 以账号、租户、项目、会话隔离，保存在当前浏览器标签页的 sessionStorage；刷新和工作空间重新挂载可恢复，退出登录与删除会话清理，存储不可用时仍可编辑。
- 会话 session 接口用同一个数据库快照读取历史与最新运行，避免运行恰好完成时漏掉回复。GET stream 回放已有 run_events 并继续监听；不会创建新任务或重新执行工具。统一消息 ID、完整分页、提交终态后才发送 finish。
- assistant-ui 原生 ResumableClientStorage、AssistantChatTransport 与 useAISDKChat 接入重连；网络错误有限重试、联网重试、手动重试，以及恢复后的后端取消。没有第二份前端消息运行时。
- 失败和取消轮次从事件恢复已记录的部分内容，显示明确终态；尚未返回的工具标记为结果未记录。部分内容用于界面展示，不伪装成完整成功回复，不改写原始数据库消息。
- 每轮可展开的过程摘要，正文持续可读；已经手动展开的过程不会因执行完成突然收起。计划和子任务作为重要内容保留独立入口。
- Skill 加载事件记录固定版本、来源、时间和调用关联。用户指定的 Skill 已在首个请求加载；Mastra 原生工具钩子对重复激活返回已有状态，每次仍检查撤销，原调用保留在事件中。
- Skill 脚本调用采用有界串行队列，最多 16 个等待或执行中的调用，单次仍只有一个沙箱；取消后等待项不得再开始。
- 工作区从真实工具结果提供 JSON、CSV 或文本下载，返回原始调用关联、子代理归属、大小和 SHA-256。CSV 单元格防公式执行，下载按运行所有者和项目校验、强制 attachment、禁止缓存和 MIME 嗅探。
- 子任务工作区显示实际队列/运行/终态、完成工具数、进行中的活动、部分或最终正文、子任务产物以及直达轨迹的链接；运行期间轮询，终态再读取最终快照。

## 验收边界

文件能力本轮覆盖实际工具结果和脚本标准输出；尚不支持从沙箱取出任意 PDF、图片或用户自建文件，也没有输入附件上传、审批暂停/恢复协议或人工接管。旧记录缺少的 Skill 加载事件不会补造。子代理保留既有单层深度与授权边界。

恢复会话使用当前已保存的事件全量回放；长会话虚拟化、基于序号的传输增量优化与跨标签页草稿同步不属于本轮实现。当前浏览器标签页关闭后，sessionStorage 草稿随之清除。未提交或部署到远端。

验证日志位于 `.scratch/chat-continuity-20260912/`，最终测试计数在本轮交付说明中记录。
