# 轨迹框选、缩放与长会话加载

日期：2026-09-13。范围为本地 Console，未发布。

## 参考与复现

实测本地 DSH 的时间轴：水平拖动会高亮选区并定位记录；滚轮可放大时间范围。采用同样的紧凑分类轨道，在保留轮次、模型请求、推理、工具和子代理关联的基础上补充导航。

已结束会话的原查询每 3 秒重读全部已加载分页；进入最近 10 轮时，10 个长轮次同时开始读取完整事件尾部。两项回归先失败，再随修复通过。另一个问题是列表在深处缩小筛选结果后，虚拟窗口起点可能超过结果末尾，导致空白。

真实网页任务会话只读统计：8 轮，81,684 条事件，原始 chunk JSON 36,965,658 字节，其中模型请求 22,263,106 字节。这个任务是用于检查大事件量，不代表 80 轮模型任务验收。

## 实现

- 最新页与历史页拆开；轮询最新活动页；更早的活动运行按需刷新其所在页，已结束的历史页不参与轮询。
- 每个轨迹阅读器最多同时读取 3 个事件尾部，优先当前关注轮次和最新轮次。取消会同时终止活动请求和排队任务。
- 按每轮 checkpoint 复用已读取事件，新增事件从上次位置继续。没有 checkpoint 的历史接口仍按原行为重读，避免把未知数据当作不可变记录。
- 后续事件分批发布；读取完整会话也按已完成轮次更新进度。导出保持逐轮检查点、数量校验和原始协议内容，导出本身不强制替换用户当前浏览范围。
- 按轮次缓存解析结果；空搜索不建立全文索引；列表摘要不再序列化完整产物。正文、参数、请求和协议导出保留完整数据。
- 时间轴支持拖动框选并定位、聚焦选区、光标锚定的滚轮缩放、Shift + 滚轮平移、按钮与键盘导航、复位。切换顺序/时长模式时重置范围。
- 同一小格内的记录聚合，点击放大并定位第一条；放大后恢复可分辨的独立节点。时长重叠轨道最多显示三层，真实开始/结束时间仍保留在详情中。
- 列表继续虚拟化，并限制缩小筛选范围后的起止索引，避免空窗口。

## 验证证据

专项测试覆盖：停止无效轮询、活动期间不重读历史页、并发上限、增量续读、取消排队、完整导出检查点与 80 轮分页、8,000 条记录的节点上限、反向框选/取消、滚轮与键盘缩放、缩放锚点/平移边界、深处筛选折叠以及缓存后的子记录关联。

真实浏览器：约 989 ms 出现可浏览的轨迹工具栏和部分事件，之后完成全部已记录内容加载。该时间是一次本机浏览器操作观测，不是稳定性能 SLA，也没有精确测定全部加载时间。完整会话投影得到 701 条阅读记录；默认窗口实际挂载 33 条列表行和 484 个时间轴节点。框选、滚轮放大与对应记录详情已实测。

只读本机基准：首个数据库轨迹页约 94 ms；完整投影约 71 ms；未变化轮次的缓存投影平均约 0.03 ms（20 次）；时长时间轴投影约 1.15 ms。该基准不包含 HTTP、React 和浏览器布局。

900 px 窗口的页面 scrollWidth 等于 clientWidth；紧凑时长概览约 197 px 高。验收后恢复默认窗口尺寸。

日志位于忽略目录 `.scratch/trace-*.log`。既有 Vite 大包提示与 jsdom CSS 解析提示仍存在。

最终检查：完整 Console suite 136/136 通过；最后补充的历史活动轮次边界及同组加载回归 6/6 通过；TypeScript、Biome、依赖边界、Vite 构建和 Ant Design lint 均通过。本轮未修改后端 API，也未执行发布。
