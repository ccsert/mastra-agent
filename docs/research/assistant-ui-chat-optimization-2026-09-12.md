## 已落地

- 以固定上游源码的 Thread、MarkdownText、TooltipIconButton、Reasoning 包装替换手工消息布局与 Markdown 排版。官方组件来源、本地插槽和能力删减记录在 `apps/console/src/shared/assistant-ui/UPSTREAM.md`。
- 消息和输入框共用最大 50rem 的阅读列；正文 15px，用户消息为右侧气泡；会话标题、版本和对话/轨迹切换合并到一行。Composer 左侧集中快捷指令与语音，右侧固定发送/停止。
- 采用官方视口与滚动行为、工具/reasoning 分组、等待指示、动作栏显示规则。最后一条助手回复保留常用操作，运行中隐藏消息动作；Markdown 代码块支持语言标识、单块复制和复制反馈，下载位于更多菜单。
- 平台业务留在 Chat feature：Skill 版本选择、结构化请求参数、知识库来源、轨迹入口、语音适配和服务端取消。`Chat.tsx` 从本批实施前 396 行收敛到 177 行；业务消息扩展移入 `ChatMessage.tsx`。
- 未发送文字和 Skill 选择保存在当前已认证项目的 QueryClient 中，按项目和会话隔离。切换会话后返回可恢复草稿；删除会话同步清草稿。没有复制 runtime 的消息状态。
- 修复响应头到达前点击停止的竞态：先等待获取 Run ID 并调用平台取消接口，成功后再终止客户端读取。取消接口失败时保留流读取并显示错误，避免先 abort 导致无法补发取消。

## 后续修复：悬停操作栏导致消息抖动

用户反馈悬停气泡时按钮显影导致画面抖动。在真实会话复现：隐藏时助手消息 footer 高 30px，显示 32px 按钮后加 6px 顶部间距变为 38px，后续消息及滚动总高度增加 8px。先前测试验证了动作可见性，没有测量显隐过程的布局稳定性。

将操作栏放入独立的 32px 预留行，与可换行的元数据分开；删除消息根节点的 30px padding/负 margin 配对，避免消息命中区域相互覆盖。继续使用官方 `hideWhenRunning` 和 `autohide="not-last"`。

Edge `127.0.0.1:5179` 实测：1562px 宽度 6 轮、1024px 宽度 4 轮历史助手回复显隐，footer 均为 38px，消息位置/高度、滚动总高度/位置及 Composer 位置差值均为 0。另检查用户气泡 2 轮显隐，位置与高度差值为 0。更多菜单可打开并用 Escape 关闭，最后回复操作仍可见；窗口尺寸已恢复，浏览器未捕获 error 日志。10 项 Chat 回归测试、类型检查、相关 Biome 检查、Console 构建与 diff 空白检查通过。
