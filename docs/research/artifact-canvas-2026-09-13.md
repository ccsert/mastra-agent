日期：2026-09-13。范围：将聊天里的内嵌产物预览移到右侧工作区，不改变产物内容或执行协议。

## 参考与交互

通过用户已打开的 `http://127.0.0.1:3080/` DSH 页面，点击交付 Markdown 文件，实际观察到右侧文件页签、独立滚动区域、收起按钮，以及左侧仍可使用的聊天和输入框。此次采用相同的布局关系。

- 聊天正文下面直接显示紧凑文件入口，不再先展开工作区才能打开最近一轮产物。旧轮次仍按需加载成果；运行详情、Skill 和子任务保留原有折叠入口。
- 桌面初始聊天 44%、产物 56%，使用 Ant Design Splitter 拖动调整，双击分隔线恢复比例。产物可放大占满会话区域、还原并排或关闭。聊天始终保留同一组件实例和输入草稿。
- 可用会话区域小于 900px 时改用 Ant Design Drawer。抽屉关闭动画结束后归还焦点，避免焦点被退出中的抽屉拦截。
- Ant Design Tabs 切换本轮文件，页签溢出由组件处理。跨轮次打开同名文件使用不同 Run URL；新增文件同步进入当前轮次页签，不抢走用户选择，也不会自行弹出已关闭的面板。
- HTML 支持自适应面板、390px 手机预览和只读源码；图片独立显示；文本/JSON 可查看原文；ZIP 等格式提供文件信息与下载。超过 2 MiB 的文本保留下载，不载入预览。
- 关闭后可从聊天顶部的文件入口重新打开；切换会话清除选择。点击面板内的关闭按钮或按 Escape 均可返回聊天。

## 实现边界

`ArtifactCanvas.tsx` 在会话内管理选中文件与左右布局；`ArtifactCard.tsx` 负责消息中的入口；`ArtifactPreview.tsx` 负责文件读取和渲染；`artifact-context.ts` 连接消息与面板。`ChatTurn` 沿用已有工作区查询并同步当前轮次产物。聊天继续复用 assistant-ui 的 Thread、运行时和输入框。

HTML 仍使用 `sandbox="allow-scripts"` 的不透明来源 iframe，CSP 在生成内容之前注入，阻止连接与外部资源。查看源码时不运行 HTML。文件切换/关闭取消读取；文件身份包含 Run、artifact ID 和 hash，迟到响应不能覆盖另一个文件。所有下载沿用既有鉴权接口。

当前是产物查看工作区，没有承诺 Canvas 内直接编辑、选区修改、跨版本 diff 或自动发布；这些需要另行接入编辑与版本协议。
