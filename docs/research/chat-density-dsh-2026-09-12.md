# 对话密度与 DSH 对照（2026-09-12）

本轮针对真实浏览器中 DSH 与平台对话的显示差异，完成本地前端调整。后端执行、消息历史、子代理授权和轨迹采集协议不变；没有新增依赖，没有发布。

## 观察到的差异

- DSH 的思考、读取、执行等动作以约 24px 单行展示。收起行已经包含动作及对象，正文占主要空间。平台原先思考卡片高 48px，另有 16px 下间距；普通工具先展开调用次数，再展开具体调用。
- 平台同时展示全局导航与 230px 会话列表，正文最大宽度只有 800px。即使宽屏，两侧仍有较多留白。
- 子代理原先在折叠外显示任务与结果，展开后再显示同一份结果 JSON；计划各版本也默认完整展开。流程越丰富，结果越容易被挤到屏幕之外。
- 输入框及底部提示原先合计约 175px，与卡片留白共同压缩阅读空间。

参考：当前浏览器的 [DSH 本地页面](http://127.0.0.1:3080/)，以及只读源代码 `.scratch/deepseek-harness/packages/client/ui-chat/src/client/chat/ReasoningRow.tsx`、`ui-tool/src/client/tool/toolviews/read-family-row.tsx`。未复制 DSH 的源码或样式。

组件实现核对了 [assistant-ui 组件文档](https://www.assistant-ui.com/docs/primitives/message) 和 [文档索引](https://www.assistant-ui.com/llms.txt)。沿用当前项目的 GroupedParts、Reasoning 和 ToolFallback，不引入第二套聊天运行时。对本地组件的扩展记录在 `apps/console/src/shared/assistant-ui/UPSTREAM.md`。

## 本次改变

1. 思考默认收起为一行：完成时预览第一行，流式输出时预览最新一行；展开阅读原始 Markdown。新 token 和完成状态不会覆盖用户手动展开/收起的选择。
2. 每次工具调用直接显示动作、参数摘要和明确结果，如“执行脚本 · scripts/summary.mjs · 退出码 0”。移除聊天中的外层调用次数折叠，一次点击即可看到结果。
3. 子代理行显示名称与任务摘要，成功后改为返回结论预览。展开内容包含任务说明和 Markdown 结果，原始执行记录单独收起。失败、取消、未执行仍可在收起状态识别。
4. 计划行展示标题、版本、完成数量及受阻数量，展开后查看原有完整计划。保留每一版，不合并或改写历史。
5. 各调用保留独立轨迹入口；参数放在结果之后，可按需展开。知识库来源、结构化表格、stdout/stderr/退出码仍可读取。工具错误从 SDK 的错误结果中提取为可读说明，原始记录仍保留。
6. 打开指定会话时默认收起会话列表，页头可随时展开或新建会话。切换列表不会卸载聊天、丢失草稿或再次请求消息历史。
7. 阅读列增至 68rem，收紧页头、输入区及上下留白。消息操作栏继续预留原有 32px 高度；工具、思考摘要固定一行且超长省略，窄屏保留 32px 点击高度。

## 仍与 DSH 不同的地方

- 脚本支持执行完成后的结构化结果、stdout/stderr；当前不是可实时追踪输出的终端会话。
- 任意工具仍按其实际返回结构展示，没有对每类文件修改、diff、网页浏览都提供专用交互。补这类能力需要明确工具结果契约。
- 子代理的聊天展开内容以任务和返回结果为主，其内部模型请求、推理和工具步骤通过轨迹入口追溯，尚未在对话中内嵌完整子任务树。

这些与界面密度是不同层面的工作，本轮不把历史数据或不存在的执行能力伪装成可用交互。
