# 对话指令与平台助手页面协作

本轮补齐对话指令，并让平台助手通过受控前端工具实际操作当前页面。已有 `platform_navigate` 只提供跳转建议；新增 `platform_ui` 负责读取页面、请求动作、等待浏览器执行回执。

## 使用方式

在普通会话、Agent 试用或平台助手的输入框中输入 `/`，可搜索系统指令与当前会话的 Skills。系统指令只在消息开头识别；正文中的路径、代码与内联 Skill 保持原有语义。

| 指令 | 行为 |
| --- | --- |
| `/clear`、`/new` | 创建同一发布版本的空白会话，保留旧会话和全部轨迹；不会删除历史 |
| `/compact [重点保留内容]` | 分段生成连续工作摘要，成功后替换后续模型请求中的旧上下文 |
| `/context` | 查看原始消息数、摘要覆盖数、最近压缩时间与摘要原文 |
| `/help` | 查看指令说明 |
| `/stop` | 停止当前运行 |
| `/skills` | 查看会话可用的 Skills |

与系统指令同名的 Skill 可通过 `/skill 名称` 选择。清理会话和压缩不允许与正在执行的任务并发；清理请求具有幂等标识，重试不会重复创建会话。

## 压缩与追溯

- 原始消息、模型请求、思考和工具事件仍保留。后续模型上下文由首条原始用户目标、历史摘要与摘要之后的新消息组成。
- 摘要任务不执行任何工具、Skill 脚本、知识库查询、子代理或页面动作；使用独立摘要指令，历史内容不能授予权限。
- Unicode 分段覆盖全部正文文本，不截掉较早的用户目标。工具载荷使用明确标记的节选，完整内容仍在原始轨迹。
- 每段都是实际模型调用，共享原任务的总 token、调用次数和超时限制；输入框显示分段进度。单次摘要输出预留至少 8192 token（受总 token 上限约束），给推理模型留出生成正文的空间。
- 只有全部分段成功且最终摘要非空、未因长度限制中断，才原子写入检查点。失败或取消不替换旧上下文。
- 每段保留模型观测；运行级用量汇总所有已执行分段。任何一段未报告的指标保持未知，不以零补齐；多段 trace 不伪造为单个 trace ID。
- 当前限制：关注点最多 1000 字符、源材料最多 100 万字符；分段大小依据配置的上下文预算作保守估算。摘要是有损整理，不是原文替代品。尚未增加自动触发压缩。

## 页面协作

在平台助手任务台打开「页面协作」，然后用自然语言要求操作。当前登记的动作包括：

- 在有权限的项目页面间导航。
- 切换 Skills、工具的项目/系统目录，搜索能力、筛选系统操作。
- 打开创建 Agent 界面、切换配置分区，填写名称、描述和指令等未保存字段。

组件通过 React 注册可用动作及当前值；助手先 `inspect` 获取页面 revision，再 `navigate` 或 `act`。前端等待页面完成加载与 React 提交，核对导航或字段值后提交成功/失败回执。模型等待回执后才能报告成功。

操作前显示 Ant Design 6.6.3 的真实 `BorderBeam` 组件，任务台收起以露出页面；底部状态条展示动作和「停止页面协作」。快速动作保留可感知的展示时间。开启减少动态效果时使用静态边框。

权限与状态边界：

- 默认关闭，只使用当前用户已有的权限；页面动作逐次校验，不因目录可见而授予执行能力。
- 一个助手会话同一时间只关联一个活动浏览器客户端。短租约随页面心跳刷新；关闭、隐藏页面、切换会话或停止协作会撤销连接。
- 动作绑定当前运行、调用 ID、客户端及页面 revision，只领取一次。过期、取消、断线或回执不确定时标记失败，不能自动重放。
- 页面存在未保存变更时，不会自动确认导航丢弃提示。
- 保存、发布、权限、凭据等未注册为页面动作，继续使用现有系统工具与变更审阅流程。当前实现不具备任意 DOM 点击或任意 JavaScript 执行能力。
