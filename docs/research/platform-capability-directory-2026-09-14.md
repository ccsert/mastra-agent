# 系统能力目录与助手能力可见性

## 已实现

- Skills 与工具页面增加「项目自定义 / 系统内置」目录。系统项只读，展示来源、版本、内容指纹、用途和详情。
- 5 个内置指导包可阅读完整指导；5 个系统工具可查看实际输入规范。41 项系统操作支持搜索、仅看可用及按需展开参数。
- 全局任务台增加「我的能力」，未配置模型时也能查看，不创建会话、不发起模型请求。
- 当前任务展示内置 Skill 成功读取次数、工具成功调用次数与最近时间。依据已保存事件汇总，重复完成事件去重，不计失败或仅开始的调用。
- 项目工具增加独立查看入口，能查看输入、输出结构而无需进入编辑器。项目 Skill 与工具均解释查看、绑定、执行和管理的区别。
- Skills 和工具页面入口改为 `resource.read`；导入保留 `resource.edit`，工具编辑与 Skill 启停保留 `resource.manage`。后端授权规则没有扩大。

## 实现边界

- `packages/contracts/src/assistant-tools.ts` 为系统工具的共享定义，运行时和目录共用描述、参数 schema 与工具分派关系。
- 能力元数据与项目业务资源分开保存；目录没有复制伪造的用户资源记录，也没有把系统工具自动绑定给业务 Agent。
- 能力目录展示未授权操作的公共定义和权限条件；执行仍使用当前用户身份逐次校验。显示目录不授予执行能力。
- `/assistant/capabilities` 返回元数据；可选 `conversationId` 必须属于当前用户及项目。历史计数只返回汇总，不返回原始输入或输出。
- `/assistant/capabilities/operations/{operationId}` 按需返回参数规范。目录初次加载不携带所有业务操作的完整 schema。
- 页面中的指导内容、参数和指纹对应当前服务定义。成功调用计数表示历史已发生的调用，不表示全部内容始终驻留于模型上下文。
- 项目能力入口可查看已有 Skills 和工具。平台助手仍按权限查询、阅读、准备业务 Agent 绑定；不会自动执行全部项目工具或 Skill 脚本。
