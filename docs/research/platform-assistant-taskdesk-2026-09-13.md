# 内置平台助手与全局任务台

2026-09-13，本地开发环境交付。入口采用用户选择的全局任务台：在保留当前页面的浮层中，左侧对话，右侧展示待应用资源、每步结果和打开资源的入口。顶栏按钮与 Cmd/Ctrl + Shift + K 可唤起或收起；任务与消息保存在服务器，草稿按用户和项目隔离。

## 已实现能力

控制面维护 41 项具名操作，Runtime 按任务调用 5 个系统工具：发现操作、读取数据、加载指导、准备变更和页面定位。操作目录由当前用户的实时权限过滤。分组返回读取操作的参数规范，创建或修改前按操作名查询完整参数规范。

| 功能 | 已接入助手的操作 | 仍由专用界面处理 |
| --- | --- | --- |
| Agent | 摘要查找、配置详情、创建/更新草稿、单独发布 | 对话试用、复杂编辑与发布验收 |
| Skills | 分页摘要、详情、文本文件、来源发现/预览/导入、创建纯指导 Skill | 本地文件上传、脚本执行授权 |
| 知识库 | 列表、创建、文档列表与固定版本原文、添加 TXT/Markdown、重试索引 | PDF/DOCX 上传预览和文档版本管理 |
| 工作流 | 分页摘要、定义、节点目录、创建/更新/校验/单独发布 | 可视化编排与运行验收 |
| 模型、工具、MCP | 发现已有资源，登记不含凭据的配置；模型与工具可按 ID 读取详情 | 凭据录入、更新、连接测试 |
| 项目与成员 | 列出可见项目、创建项目、查看权限、成员查询、项目角色调整、审计查询 | 邀请令牌、团队所有者、账号和密码管理 |
| 应用与运行节点 | 应用状态摘要、功能解释和受权限约束的页面入口 | 创建/轮换应用凭据、节点部署 |

五个内置指导包为：平台使用向导、创建业务智能体、编排业务流程、资料与 Skills 管理、权限与访问协作。当前是版本化的内置指导内容，由专用工具按需读取；不执行脚本，不授予额外权限，也不安装到用户的 Skills 目录。

## 执行与权限边界

- 内置助手使用内部资源类型和服务器保存的任务标识。普通 Agent 的描述、指令或工具参数不能获得系统助手身份。
- 每位用户使用自己的会话，项目权限在调用系统工具、领取任务和应用操作时重新检查。只读角色可使用助手问答，但不能通过助手创建资源。
- 模型只能生成待审阅方案，不能调用应用接口。方案属于当前用户的任务，最多 8 步，1 小时有效；后一步可引用前一步真实创建的资源 ID。
- 应用时检查当前权限、原始参数和目标草稿版本；发布与成员权限变更必须为独立方案。业务操作复用原有领域服务，保持项目隔离和已有校验。
- 并发或重复应用同一方案不会重复创建。每步先记录执行状态，再保存结果。失败保留成功步骤；无法确定执行结果时明确标为未知，不自动重放。
- 方案是逐步执行，不是跨资源事务。服务器在应用中退出可能保留“应用中/结果未知”，需先检查资源再准备后续动作。
- 密钥、密码、Cookie 和应用凭据不进入系统工具结果；创建配置时凭据字段被拒绝。现有凭据继续由服务器用于模型调用，用户在受保护表单中维护。

## 对话与页面体验

复用 assistant-ui 会话组件、现有消息事件、取消、恢复和轨迹。新的系统操作显示中文名称和图标，内置指导可展开阅读；参数发现、资源查询和变更建议不会再自动生成一屏 JSON/CSV 下载产物。

开始构建时，服务器用幂等请求标识创建任务并发送首条消息；客户端恢复已有运行，不再次发送。空任务直接显示输入框。收起任务台保留会话和草稿，历史任务可以重新打开。

资源列表优先返回摘要，按 ID 查询详情，Skills 文本返回经完整性校验后解码的正文，不让模型自行猜测 Base64。内置助手新任务使用 16k 上下文、20 步、24 次模型请求、400k 单轮预算上限、2k 单次输出上限；预算是保护上限，不是预计消耗。右侧清单负责操作计划，避免再维护一份重复的模型计划。

## 后续界面操作的衔接

当前已经支持类型化、受权限检查的页面定位建议，由用户点击后导航；还没有实现自动点击、填表或浏览器控制。

下一层可沿用现有操作目录，增加稳定的页面/资源/表单字段标识，以及“观察页面 → 展示目标区域 → 填入待审阅值 → 提交”的语义动作。界面动作仍需绑定当前用户、项目、页面版本和具体资源，提交复用同一领域服务与审计；页面内容和 Skill 不能改变授权。凭据字段应由用户直接填写，模型只接收已配置状态。这样可以让助手操作本系统界面，同时保持 API 与界面操作的权限和结果一致。
