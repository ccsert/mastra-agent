# 成员权限与 Agent 工作区交付记录

日期：2026-09-13。实现对象：当前本地工作区，开发页面 `http://127.0.0.1:5179`。承接 [平台功能审阅](./platform-management-and-agent-authoring-2026-09-13.md) 的第 1、2 阶段。

代码仍包含前序未提交改动，本记录不以仓库 HEAD 代表交付版本。本轮未提交、推送或部署远端。

## 已实现

### 团队和项目权限

- 全局「团队设置」：成员邀请、账号角色与启停、撤销登录会话、团队所有权移交、邀请记录与操作记录。
- 项目内「项目设置」：添加已有团队成员、邀请新成员、调整项目角色、移除项目访问。团队所有者和管理员继承项目管理权。
- 新账号通过邀请链接加入。链接 3 天有效、只能接受一次，可撤销；服务端仅保存 token 哈希。链接放在 URL fragment 中，接受邀请时由页面提交，不通过导航 URL 的查询参数传递。不会自动发邮件或消息。
- 服务端根据当前数据库中的账号状态和成员关系授权，不把登录时的角色当作长期授权。跨项目/租户访问、禁用账号、旧邀请、非所有者提升管理员均有测试。
- 会话及运行保持 `actor_id + entry` 隔离；管理员不能据角色直接读取他人会话。移交所有权保留唯一所有者，原所有者降为团队管理员。
- 记录成员、邀请、会话撤销、所有权移交，以及 Agent 发布/试用创建操作。本轮不包含所有业务资源修改的完整审计。

| 项目角色 | 当前能力 |
| --- | --- |
| 管理员 | 项目成员管理、模型/工具/MCP/应用配置、Agent 编辑与发布、调用 |
| 编辑者 | Agent 配置和草稿试用、已发布 Agent 调用、Skill 导入、知识库与工作流编辑 |
| 使用者 | 查看和调用已发布 Agent；列表展示已发布配置，不展示尚未发布的草稿 |
| 只读成员 | 查看 Agent 配置及资源只读 API；不允许写入、发布或运行。独立资源管理页目前仍按操作角色开放 |

编辑者不能新授予 Skill 脚本执行权限，不能启停 Skill 版本。可以保留同 Agent 正式版本已批准的同版本脚本入口；引用更新的 Skill 版本须重新由管理员授权。普通指令资料的导入和使用与脚本授权分开。

权限检查与项目元数据读取合并，删除目录接口重复授权查询，保留原有固定查询预算测试。应用凭据仍可调用已发布工作流并查询自身运行结果。

### Agent 独立工作区

入口：Agent 卡片「配置 Agent」，或「创建 Agent」。

- 从侧边抽屉改成独立工作区：左侧配置分组，中间表单，右侧草稿试用；顶部显示草稿修订、保存状态和正式版本。
- 用途与指令、知识与技能、工具、运行设置、发布记录分组显示，切换分组保留表单值。
- 提供知识问答、业务执行、复杂任务起点；任务预算提供日常、持续迭代、复杂任务档位，高级参数按需展开。
- 保存后留在工作区，新建成功后进入真实 Agent 地址。保存已成功但试用创建失败时仍保留草稿和地址，支持重试。
- 试用固定某一草稿修订，复用现有执行、聊天、用量和轨迹机制。修改后提示当前试用仍使用旧修订，重新试用创建独立会话。
- 收起试用保留已挂载会话；同一浏览器会话中重新打开或刷新工作区，可恢复上次选择的试用及服务器历史。选择记录按当前用户和项目隔离，退出时清理；服务器仍校验访问权。
- 执行期间锁定保存、发布和重新试用。未保存修改有离开提示；冲突或保存失败可显式「读取最新草稿」。
- 发布前展示配置分组变更和能力数量，确认后才发布。普通会话继续使用正式版本，既有会话保留原快照。
- 草稿快照在 releases 中使用独立 `preview` 类型，内部版本为 0；界面显示「草稿试用」。正式版本查询及工作流能力目录排除预览；预览不会推进正式版本号。
- 编辑者降为使用者后，草稿试用的详情、运行、事件、列表及轨迹读取被拒绝或过滤。

## 数据迁移

新增迁移 15（成员/邀请/审计）和 16（草稿快照）。迁移通过现有事务与 advisory lock 执行。

既有用户原本拥有管理能力，迁移时保留为团队管理员；每个租户按稳定 ID 排序确定一名所有者。新初始化账号为所有者，新邀请账号为团队成员。现有正式 releases 保留为 published，旧会话继续引用原 release。

这是开发库迁移已运行的实现；生产升级、备份与回滚演练尚未开展。
